# רשימת קניות + השוואת ביטוחי בריאות

שתי אפליקציות בפרויקט אחד, בעברית ובכיוון RTL, שנבנו עם Next.js, TypeScript ו-Tailwind CSS: רשימת קניות לסופר, ומנוע להשוואת פוליסות ביטוח בריאות.

## רשימת קניות (`/`)

- **קטגוריות ופריטים מוגדרים מראש** — ירקות ופירות, מוצרי חלב, בשר ודגים, מאפים, שימורים, חטיפים, משקאות, קפואים, ניקיון, טיפוח ועוד.
- **הוספת מוצר מותאם אישית** — שם, קטגוריה ויחידת מידה (יח', ק"ג, גרם, ליטר, חבילה).
- **ניהול הרשימה** — סימון פריט כנקנה, עדכון כמות, מחיקת פריט.
- **העתקת רשימה** — ייצוא הרשימה המלאה כטקסט מסודר לפי קטגוריות, להעתקה ולשיתוף.
- **ניקוי הרשימה** — עם אישור לפני מחיקה.
- **שמירה אוטומטית** — הרשימה נשמרת בדפדפן (`localStorage`) ונטענת מחדש בכל ביקור.

## השוואת ביטוחי בריאות (`/insurance`)

מנוע להזנת פוליסות ביטוח בריאות (פרטי, קולקטיבי, שב"ן) והשוואה ביניהן:

- **הזנת פוליסות** — שם, חברת ביטוח, סוג פוליסה, פרמיה חודשית ובחירת תחומי כיסוי (ניתוחים בארץ/בחו"ל, מחלות קשות, תרופות מחוץ לסל, סיעוד, שיניים, הריון ועוד).
- **ייבוא אוטומטי מ-PDF** — העלאת קובץ PDF של דוח הפוליסה; Claude (Anthropic API) קורא את המסמך וממלא אוטומטית את פרטי הפוליסה לבדיקה ואישור המשתמש לפני השמירה (`POST /api/insurance/extract`). דורש הגדרת `ANTHROPIC_API_KEY` בסביבת השרת — ראו `.env.example`.
- **איתור כפילויות כיסוי** — זיהוי תחומים המכוסים על ידי יותר מפוליסה אחת, עם הערכת החיסכון החודשי האפשרי בביטול הכיסוי הכפול.
- **מיפוי סיכונים** — איתור תחומי כיסוי ליבה (כמו מחלות קשות או סיעוד) שאין להם כיסוי בכלל, מדורגים לפי רמת סיכון (גבוה/בינוני/נמוך).
- **המלצות לפעולה** — רשימת המלצות מדורגת המבוססת על הכפילויות והפערים שנמצאו.
- **הפקת דוח** — ייצוא סיכום מלא (פוליסות, כפילויות, סיכונים והמלצות) כטקסט להעתקה.
- **שמירה אוטומטית** — הפוליסות נשמרות בדפדפן (`localStorage`) ונטענות מחדש בכל ביקור.

## סטאק טכנולוגי

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS 4
- `useSyncExternalStore` לניהול מצב הרשימה/הפוליסות, עם התמדה ב-`localStorage`
- [Anthropic SDK](https://www.npmjs.com/package/@anthropic-ai/sdk) + Zod — ייבוא אוטומטי של פוליסות מ-PDF (`/api/insurance/extract`)

## הרצה מקומית

```bash
npm install
npm run dev
```

האתר יעלה בכתובת [http://localhost:3000](http://localhost:3000).

כדי להפעיל את ייבוא הפוליסות האוטומטי מ-PDF ב-`/insurance`, העתיקו את `.env.example` ל-`.env.local` והגדירו בו `ANTHROPIC_API_KEY`. בלי המפתח שאר האפליקציה (כולל הזנת פוליסות ידנית) עובדת כרגיל — רק הייבוא האוטומטי יציג הודעת שגיאה ברורה.

## בדיקות

```bash
npm run lint   # ESLint

```

## מבנה הפרויקט

```
src/
  app/
    page.tsx                        # מסך רשימת הקניות
    insurance/page.tsx               # מסך השוואת ביטוחי הבריאות
    api/insurance/extract/route.ts    # חילוץ פוליסה מ-PDF באמצעות Claude
  components/                          # רכיבי UI כלליים (מודלים, טוסט) ותת-תיקיית insurance/
  hooks/                                # ניהול מצב הרשימה, הפוליסות וטוסטים
  lib/                                   # קטגוריות, טיפוסים, ה-store-ים שמתמידים ב-localStorage
    insurance/                            # מנוע ההשוואה: types, categories, store, engine, extraction (סכימת Zod)
```
