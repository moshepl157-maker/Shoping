# רשימת קניות

אפליקציית רשימת קניות לסופר, בעברית ובכיוון RTL, שנבנתה עם Next.js, TypeScript ו-Tailwind CSS.

## תכונות

- **קטגוריות ופריטים מוגדרים מראש** — ירקות ופירות, מוצרי חלב, בשר ודגים, מאפים, שימורים, חטיפים, משקאות, קפואים, ניקיון, טיפוח ועוד.
- **הוספת מוצר מותאם אישית** — שם, קטגוריה ויחידת מידה (יח', ק"ג, גרם, ליטר, חבילה).
- **ניהול הרשימה** — סימון פריט כנקנה, עדכון כמות, מחיקת פריט.
- **העתקת רשימה** — ייצוא הרשימה המלאה כטקסט מסודר לפי קטגוריות, להעתקה ולשיתוף.
- **ניקוי הרשימה** — עם אישור לפני מחיקה.
- **שמירה אוטומטית** — הרשימה נשמרת בדפדפן (`localStorage`) ונטענת מחדש בכל ביקור.

## סטאק טכנולוגי

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS 4
- `useSyncExternalStore` לניהול מצב הרשימה, עם התמדה ב-`localStorage`

## הרצה מקומית

```bash
npm install
npm run dev
```

האתר יעלה בכתובת [http://localhost:3000](http://localhost:3000).

## בדיקות

```bash
npm run lint   # ESLint
npm run build  # בנייה לפרודקשן + בדיקת טייפים
```

## מבנה הפרויקט

```
src/
  app/
    page.tsx           # מסך האפליקציה הראשי
  components/           # רכיבי UI (בחירת קטגוריה, רשימה, מודלים)
  hooks/                 # ניהול מצב הרשימה וטוסטים
  lib/                    # קטגוריות, טיפוסים, ה-store שמתמיד ב-localStorage
```
